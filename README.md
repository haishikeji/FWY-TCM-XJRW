### 系统功能说明

- 系统管理：包括用户管理、角色管理、菜单管理、通知公告、日志管理等功能，可以对系统进行基础的配置和管理。
- 巡检管理：包括巡检区域管理、巡检点管理、巡检线路管理、巡检计划管理、巡检任务管理等功能，可以对巡检工作进行全面的计划和管理。
- 工单中心：包括类型设置、流程管理、工单、待办任务、流程监控等功能，可以对巡检过程中产生的问题进行跟踪处理。
